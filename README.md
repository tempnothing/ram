# Operating Systems Lab Programs

Programs extracted from `DOC-20261111-WA0003.docx` and organized by experiment.

- Experiments 1-2 and 4-10 preserve the document's C programs.
- Experiment 3 was titled Shell Programming; its six algorithms were converted to equivalent C programs because every requested output file is a `.c` file.
- Programs requiring POSIX threads or semaphores generally compile with `-pthread`.
- Programs using System V IPC require Linux/GNU/Linux.

Compile example:

```sh
gcc experiment2/forkp1.c -o forkp1
./forkp1
```
